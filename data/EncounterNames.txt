# WHERE THESE NAMES CAME FROM

# From FFTPatcher's ENTD event-name lists:
#   https://github.com/Glain/FFTPatcher
#   PatcherLib.Resources/Resources/PSP/EventNames.xml

#   Copyright 2007 Joe Davidson and the FFTPatcher contributors.
#   Licensed GNU GPL v3 or later - see LICENSE in the project root, which is
#   why Mod Studio itself is GPL-3.0.
#
# FFTPatcher lists these ids in HEX; they are converted to decimal here,
# because that is what the .nxd files and this tool use. FFTPatcher's 1CC is
# this file's 460.
#
# Two lists are merged. The PSP (War of the Lions) names are used wherever
# they exist, because The Ivalice Chronicles uses that translation's naming
# - its own item list says "Wizard's Rod" and "Thief's Cap", not the PSX
# "Wizard Rod" and "Thief Hat". Where PSP has no entry, the older PSX-US
# name is used instead. Those 106 entries may read differently from the
# game's own wording (PSX-US calls 460 "St Murond Temple" where the game and
# PSP call it Mullonde Cathedral). They are listed at the bottom of this
# file under their own heading rather than marked on each line.
#
# These names describe the original Final Fantasy Tactics. The Ivalice
# Chronicles is a remaster and its own wording may differ, and any entry not
# in either list simply isn't named. Corrections are welcome - just edit the
# line.
#
