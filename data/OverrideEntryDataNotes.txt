Override Entry Data Notes


Key - The Encounter being edited (Full list of encounters can be viewed in FFTPatcher's ENTD Tab although FFTPatcher uses hexadecimal instead of decimal for instance 1B7 which is Chapter 4 - Lost Halidom tranlating 1B7 to decimal 439 for key also edits that same encounter in The Ivalice Chronicles as our nxd uses decimal 
Unknown4 - This one handles the Name of the unit (List of names in charaname.en.nxd) 
EntryUnknown1D - This one handles the Primary Skillset of the unit (Mod Studio calls these Job Commands so I guess later on when a user edits SecondarySkillset we should call those Secondary Job Command in Mod Studio) 
Level - Just like in FFTPatcher's ENTD tab there are unique properties for some vaules that allow you to match the party level or set it some levels above the party level ect 
Job Level - Job level will only change to the number you set it (max is level 8) if JobUnlock matches the job they currently have selected (0 = Squire / Special Job 1 = Chemist 2 = Knight ect matching the "Jobs Unlocked" list in FFTPatcher's ENTD tab with the exception of DarkKnight OnionKnight and I think Unknown as they were removed in The Ivalice Chronicles) unless that job is Chemist or Squire in that case setting Job Unlock to Mine With Job Level 8 will work because Chemist and Squire need to be Level 8 to unlock Mine anyways. If the unit is a special unit with a unique job command it is treated the same as a squire. 
Unknown8E - If set to 1 unit has the Special Unit Marker & Gold Health Bar 
Unknown 91 - If set to 1 unit has the Objective Marker Top Portrait 
Unknown 92 - If set to 1 unit has the Objective Marker Bottom Portrait - Overrides Special Unit Marker 
Unknown 99 - If set to 1 the unit has the First Turn
